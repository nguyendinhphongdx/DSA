## Cách sử dụng

Mỗi thư mục chứa:
- `README.md` - Lý thuyết & ghi chú
- `examples.js` - Ví dụ minh họa
- `practice.js` - Bài tập luyện tập
- `solution.js` - Lời giải

Chạy file:
```bash
node <đường-dẫn-file>.js
```
