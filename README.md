# DSA - Data Structures and Algorithms Review

Welcome to the DSA repository! This repository is organized for systematic review and practice of Data Structures and Algorithms.

## Repository Structure

### 📊 DataStructures/
Fundamental data structures organized by topic with progressive sessions:
- **Arrays/** - Array operations, manipulation, and algorithms
- **LinkedLists/** - Singly, doubly, and circular linked lists
- **Stacks/** - LIFO data structure implementations and applications
- **Queues/** - FIFO data structure implementations and applications
- **Trees/** - Binary trees, BST, AVL, and tree traversals
- **Graphs/** - Graph representations and basic operations
- **HashTables/** - Hash maps, hash sets, and collision handling
- **Heaps/** - Min/max heaps and priority queues

### 🔧 Algorithms/
Core algorithms organized by category with progressive sessions:
- **Sorting/** - Bubble, merge, quick, heap sort, etc.
- **Searching/** - Binary search, linear search, and variations
- **DynamicProgramming/** - DP patterns and optimization problems
- **Greedy/** - Greedy algorithm strategies and applications
- **DivideAndConquer/** - Recursive problem-solving approaches
- **Backtracking/** - Constraint satisfaction and combinatorial problems
- **GraphAlgorithms/** - BFS, DFS, Dijkstra, MST, etc.
- **StringAlgorithms/** - Pattern matching, string manipulation

### 💡 ProblemSolving/
Practice problems organized by difficulty:
- **Easy/** - Fundamental problems for building confidence
- **Medium/** - Intermediate problems combining multiple concepts
- **Hard/** - Advanced problems requiring complex solutions

## How to Use This Repository

1. **Session-Based Learning**: Each topic is divided into sessions for progressive learning
2. **Start with Fundamentals**: Begin with DataStructures before moving to Algorithms
3. **Practice Regularly**: Use ProblemSolving section to apply learned concepts
4. **Track Progress**: Create solution files in respective session folders

## Session Structure

Each session folder can contain:
- Solution files (e.g., `solution.py`, `solution.java`, `solution.cpp`)
- Notes and explanations (e.g., `notes.md`)
- Test cases (e.g., `test.py`)
- Complexity analysis

Happy Learning! 🚀
