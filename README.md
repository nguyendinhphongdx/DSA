## Lộ trình học

### Phase 1: Nền tảng
1. Arrays & Strings
2. Linked List
3. Stack & Queue
4. Hash Table
5. Sorting & Searching

### Phase 2: Nâng cao
6. Tree (Binary Tree, BST, Trie)
7. Heap / Priority Queue
8. Graph (BFS, DFS)
9. Recursion & Backtracking

### Phase 3: Chuyên sâu
10. Dynamic Programming
11. Greedy
12. Graph nâng cao (Dijkstra, Topological Sort, MST)
13. Divide and Conquer
14. Bit Manipulation

### Phase 4: Kỹ thuật giải bài
15. Two Pointers
16. Sliding Window
17. Binary Search nâng cao

## Cách sử dụng

Mỗi thư mục chứa:
- `README.md` - Lý thuyết & ghi chú
- `implementation.js` - Cài đặt cấu trúc dữ liệu / thuật toán
- `practice.js` - Bài tập luyện tập
- `solution.js` - Lời giải

Chạy file:
```bash
node <đường-dẫn-file>.js
```
