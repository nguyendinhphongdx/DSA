# Data Structures

This section contains implementations and exercises for fundamental data structures.

## Topics

### Arrays
- **Session1**: Introduction, basic operations, traversal
- **Session2**: Advanced array algorithms, two-pointer technique

### LinkedLists
- **Session1**: Singly linked list, basic operations
- **Session2**: Doubly linked list, circular lists, advanced problems

### Stacks
- **Session1**: Implementation, stack-based problems, applications

### Queues
- **Session1**: Queue implementation, circular queue, deque

### Trees
- **Session1**: Binary tree basics, traversals (inorder, preorder, postorder)
- **Session2**: Binary Search Trees, AVL trees, tree problems

### Graphs
- **Session1**: Graph representations, adjacency matrix/list, basic operations

### HashTables
- **Session1**: Hash functions, collision handling, implementation

### Heaps
- **Session1**: Min/max heap, heap operations, priority queue

## Learning Path

1. Start with **Arrays** and **LinkedLists** - foundation structures
2. Move to **Stacks** and **Queues** - linear structures with constraints
3. Progress to **Trees** - hierarchical structures
4. Study **Graphs** - complex relationship modeling
5. Master **HashTables** and **Heaps** - optimization structures

## Practice Tips

- Implement each data structure from scratch
- Analyze time and space complexity
- Solve at least 3-5 problems per session
- Compare different implementation approaches
