# Problem Solving

This section contains practice problems organized by difficulty level.

## Difficulty Levels

### Easy
Problems that test fundamental understanding of basic data structures and algorithms.
- Focus on single concepts
- Straightforward implementations
- Good for building confidence and speed

**Recommended Topics:**
- Array traversal and basic operations
- Simple string manipulation
- Basic linked list operations
- Stack and queue fundamentals
- Basic recursion

### Medium
Problems that combine multiple concepts and require deeper algorithmic thinking.
- Multiple steps or techniques
- Moderate optimization required
- Common interview questions

**Recommended Topics:**
- Two-pointer technique
- Sliding window
- Binary search variations
- Tree and graph traversals
- Dynamic programming basics
- Greedy algorithms

### Hard
Advanced problems requiring complex algorithms and optimization.
- Multiple concepts combined
- Advanced data structures
- Complex optimization
- Challenging interview questions

**Recommended Topics:**
- Advanced dynamic programming
- Complex graph algorithms
- Advanced tree problems
- Backtracking with optimization
- Segment trees, Fenwick trees
- Computational geometry

## Approach to Problem Solving

1. **Understand**: Read problem carefully, identify inputs/outputs
2. **Plan**: Choose appropriate data structure and algorithm
3. **Implement**: Write clean, readable code
4. **Test**: Verify with examples and edge cases
5. **Optimize**: Analyze and improve complexity
6. **Review**: Learn from solutions and alternative approaches

## Session Organization

Each session folder should contain:
- Problem statements or links
- Your solution implementations
- Test cases
- Complexity analysis
- Alternative approaches and learnings
