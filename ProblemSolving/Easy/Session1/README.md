# Easy Problems - Session 1

## Focus Areas
- Array fundamentals
- String basics
- Simple iteration and conditionals

## Recommended Problems

### Arrays
1. **Two Sum**: Find two numbers that add up to target
2. **Best Time to Buy and Sell Stock**: Find maximum profit
3. **Contains Duplicate**: Check if array has duplicates
4. **Maximum Subarray**: Find contiguous subarray with largest sum

### Strings
1. **Valid Anagram**: Check if two strings are anagrams
2. **Valid Palindrome**: Verify if string is palindrome
3. **Reverse String**: Reverse characters in string

### Linked Lists
1. **Reverse Linked List**: Reverse a singly linked list
2. **Merge Two Sorted Lists**: Combine two sorted lists

### Other
1. **Valid Parentheses**: Check balanced brackets using stack
2. **Climbing Stairs**: Basic dynamic programming

## Tips
- Start with brute force, then optimize
- Test with edge cases: empty input, single element, duplicates
- Focus on clarity before optimization
