# Algorithms

This section contains implementations and exercises for fundamental algorithms.

## Topics

### Sorting
- **Session1**: Bubble sort, selection sort, insertion sort (O(n²) algorithms)
- **Session2**: Merge sort, quick sort, heap sort (O(n log n) algorithms)

### Searching
- **Session1**: Linear search, binary search, search variations

### DynamicProgramming
- **Session1**: Introduction to DP, memoization, basic DP problems
- **Session2**: Advanced DP patterns (knapsack, LCS, LIS, matrix chain)

### Greedy
- **Session1**: Greedy strategy, activity selection, interval problems

### DivideAndConquer
- **Session1**: Recursive approach, master theorem, classic problems

### Backtracking
- **Session1**: Constraint satisfaction, combinatorial search, pruning

### GraphAlgorithms
- **Session1**: BFS, DFS, topological sort, cycle detection
- **Session2**: Dijkstra, Bellman-Ford, Floyd-Warshall, MST (Prim, Kruskal)

### StringAlgorithms
- **Session1**: Pattern matching (KMP, Rabin-Karp), string manipulation

## Learning Path

1. Master **Sorting** and **Searching** - fundamental techniques
2. Study **DivideAndConquer** - problem decomposition
3. Learn **DynamicProgramming** - optimization technique
4. Understand **Greedy** - local optimal choices
5. Practice **Backtracking** - exhaustive search with pruning
6. Explore **GraphAlgorithms** - complex relationship traversal
7. Apply **StringAlgorithms** - text processing

## Practice Tips

- Understand the algorithm before coding
- Analyze time and space complexity
- Implement iterative and recursive versions
- Test with edge cases and large inputs
- Compare algorithm performance
