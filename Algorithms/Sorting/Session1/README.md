# Sorting Algorithms - Session 1

## Topics Covered
- Bubble Sort
- Selection Sort
- Insertion Sort

## Learning Objectives
- Understand comparison-based sorting
- Implement O(n²) sorting algorithms
- Compare performance characteristics
- Identify use cases for simple sorts

## Algorithms

### Bubble Sort
- Time Complexity: O(n²) average and worst case
- Space Complexity: O(1)
- Stable: Yes
- Use case: Small datasets, educational purposes

### Selection Sort
- Time Complexity: O(n²) all cases
- Space Complexity: O(1)
- Stable: No
- Use case: Small datasets, memory-constrained

### Insertion Sort
- Time Complexity: O(n²) worst case, O(n) best case
- Space Complexity: O(1)
- Stable: Yes
- Use case: Nearly sorted data, small datasets, online sorting

## Practice Problems
1. Implement each sorting algorithm from scratch
2. Sort array of integers in ascending/descending order
3. Count number of swaps in bubble sort
4. Analyze performance on different input types
