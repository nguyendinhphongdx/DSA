# Design Patterns - Bài tập tổng hợp

## Bài tập

### Bài 1: E-Commerce System
Áp dụng nhiều patterns vào hệ thống e-commerce:
- **Singleton**: CartManager
- **Factory**: PaymentMethodFactory
- **Strategy**: Discount strategies
- **Observer**: Order events
- **Decorator**: Product features

### Bài 2: Game Character System
- **Builder**: CharacterBuilder
- **Prototype**: Clone character templates
- **State**: Character states (idle, attack, defend, dead)
- **Command**: Undo/redo actions

### Bài 3: Notification System
- **Abstract Factory**: NotificationFactory (Email, SMS, Push)
- **Adapter**: Wrap third-party notification services
- **Observer**: Subscribe to events
- **Template Method**: Base notification flow

Xem file `practice.js` để bắt đầu.
