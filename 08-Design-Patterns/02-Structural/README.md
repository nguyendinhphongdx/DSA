# Structural Patterns - Patterns tổ chức cấu trúc

## Tổng quan

Structural patterns kiểm soát cách **tổ chức class/object** với nhau để tạo cấu trúc lớn hơn.

| Pattern | Mục đích | Ví dụ thực tế |
|---------|---------|---------------|
| **Adapter** | Chuyển đổi interface | API adapter, XMLToJSON |
| **Decorator** | Thêm behavior động | Logger, Cache middleware |
| **Facade** | Interface đơn giản | jQuery, API Client |
| **Proxy** | Kiểm soát truy cập | Lazy loading, Rate limiter |
| **Composite** | Cấu trúc cây | File system, Menu |
| **Bridge** | Tách abstraction/implementation | Shape + Color |
